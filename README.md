# 训练倒计时

一个可安装到 iOS Edge 浏览器（WebKit 内核）主屏幕的训练间歇倒计时 PWA。纯 HTML/CSS/JS 实现，无构建工具、无外部依赖（SortableJS 已本地化到 `js/vendor/`）。

## 功能

- 可设置训练时长（默认 30 秒，最短 20 秒）与休息时长（默认 15 秒，最短 10 秒），并持久化到 localStorage。
- 列表：自由增删、编辑名称、拖拽排序（触摸友好）、指定起始段。
- 完整流程：准备倒计时 10 秒（逐秒语音报数）→ 训练（开始时播报段名，最后 10 秒逐秒报数）→ 休息（开始播报"休息"，最后 5 秒逐秒报数）→ 循环，最后一段结束播报"训练完成"。
- 控制：开始 / 暂停 / 继续 / 跳过 / 重置；跳过直达下一训练（不经过休息），最后一段跳过即结束。
- 运行高亮：训练中高亮当前训练，休息中高亮即将开始的下一段，准备中高亮起始段。
- 运行窗口：开始后列表变为固定高度的滚动容器（最多同时显示 4 个训练），可手动滑动查看全部训练；阶段切换时列表平滑滚动居中当前训练，高亮同步平滑过渡。运行面板标注第几段进度。
- 总时长汇总：列表底部实时计算并显示计划总时长（训练 + 段间休息）。
- 过半播报：训练到达中点前 1 秒语音播报"过半"一次。
- 计划导出/导入：一键导出训练计划为 JSON 文件，Edge 清理数据后可通过导入恢复。
- 防熄屏：优先 Screen Wake Lock API，失败时回退隐藏静音视频（iOS/WebKit 用 mp4，其余内核用 webm）。
- 后台恢复：回到前台按真实时间戳重新计算阶段与剩余时间，不补播错过的报数。
- 静音拨片提示：首次运行时提示检查 iPhone 静音开关，可关闭并记忆。

## iOS Edge 安装

**在线地址（GitHub Pages）**：<https://cui-zheng-1128.github.io/TrainingCounter/>

1. 部署：仓库已启用 GitHub Pages，`main` 分支推送后自动部署到上述地址；若自行部署，将仓库内文件上传到任意 https 静态站点即可。
2. 用 iOS Edge 打开上述地址，等待页面加载完成后刷新一次，让离线缓存接管（之后可离线运行）。
3. 点击底部菜单 `...`，选择"添加到主屏幕"。
4. 从主屏幕图标启动，即以独立应用模式运行。
5. 更新：本地修改推送到 `main` 后，重新打开应用并刷新一次页面即可获取新版本。

## 使用说明

1. 在"设置"中填写训练时长（默认 30 秒，最短 20 秒）与休息时长（默认 15 秒，最短 10 秒），列表底部会实时显示计划总时长（训练 + 段间休息）。
2. 在"列表"中增删训练、编辑名称、拖动调整顺序，并勾选起始段；未勾选时默认从第一段开始。
3. 可通过"导出计划"把当前计划保存为 JSON 文件（建议存入"文件"App），Edge 清理数据后用"导入计划"恢复。
4. 点击"开始"：先在当前手势内解锁音频并启用防熄屏，显示加载动画等待全部语音资源就绪，随后进入 10 秒准备倒计时。
5. 运行中的语音：进入训练时播报该段名称；训练最后 10 秒逐秒报数；到达中点前 1 秒播报"过半"；训练结束播报"休息"（休息最后 5 秒逐秒报数）；全部完成播报"训练完成"。
6. 运行中的控制与显示：可暂停、继续、跳过与重置，跳过直达下一段（不经过休息）；列表变为固定高度滚动窗口（最多显示 4 个），自动居中并高亮当前训练，可手动滑动查看；运行面板标注当前进度（第几段 / 总段数）；运行期间设置与列表不可编辑。
7. 请确保 iPhone 侧面静音开关关闭，否则无法听到语音。

## 已知限制

- iOS 静音拨片打开时无法播放任何声音，请保持其关闭。
- 防锁屏仅在页面处于前台时有效；切后台时 iOS 会冻结 JS。
- 切后台期间计时由时间戳恢复，错过的阶段与报数不会补播。
- 过半在到达中点前 1 秒播报；训练设为 20 秒时，"10"紧邻过半播报且位于其播放中途，此时"10"让位不重复播报。
- iOS 16.4~18.3 独立模式下原生 Wake Lock 无效，因此采用静音视频兜底。
